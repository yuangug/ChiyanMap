# 洞穴模式

## 概述

洞穴模式是 ChiyanMap 专为地下探索设计的渲染模式。当地下时，地图自动从"地表俯视图"切换到"洞穴横截面"，让玩家清晰看到脚下和周围的洞穴结构。

---

## 自动检测是否进入洞穴

`PlayerHook.h:441` `IsPlayerUnderground()`

在玩家头顶 Y+2 到 Y+22 的范围（最多至 Y=319），检查 5 个位置：

```
位置偏移：(0,0), (1,0), (-1,0), (0,1), (0,-1)
```

每个位置从 Y+2 向上找第一个固体方块（排除树叶和原木）。**5 中至少 3 个有固体 → 判定为地下。**

### 特殊：下界

下界（`dimId == 1`）**强制开启洞穴模式**，跳过检测。

### 触发时机

每次重新扫描时检测：

```cpp
// PlayerHook.h:720
if (!isScanning && (|px - lastScanX| >= 16 || |pz - lastScanZ| >= 16 || 超时100tick))
```

- 玩家移动超过 16 格
- 或 100 tick（约 5 秒）未扫描

### 模式切换时的处理

从洞穴 ↔ 地表切换时，清除整个地图缓存 `g_mapColors` 和 `g_mapHeights`，重新扫描。

---

## 基准高度 caveScanY

`MapRenderState::caveScanY`

每次扫描时更新为玩家当前 Y 坐标：

```cpp
// PlayerHook.h:742-745
if (caveMode) {
    caveScanY = (int)g_playerY;
}
```

**使用玩家脚下的 Y 坐标，不向上偏移。**

## 扫描渲染逻辑

`PlayerHook.h:790-849`

### 核心思想

对地图上每个格子 `(x, z)`，检查玩家 Y 层附近的方块，区分"通道"和"墙壁"。

### 步骤

```
检查 (targetX, csy, targetZ) → 向上扫描到天花板（最多64格）
  │
  ├─ 途中有空气 → 洞穴通道
  │    └─ 向下无上限搜索地板 → 画地板方块颜色
  │         ├─ 找到地板 → 原色显示
  │         └─ 没地板 → 深灰色 (0.15, 0.15, 0.15)
  │
  └─ 全是固体 → 墙壁
       └─ 黑色 (0, 0, 0, 1)
```

#### 1. 空气检测（是否通道）

```cpp
// PlayerHook.h:796-803
bool isAir = false;
for (int dy = 0; dy <= 64; dy++) {
    Block block = getBlock(targetX, csy + dy, targetZ);
    if (block is solid) break;   // 碰到天花板 → 停止
    isAir = true;                // 至少有一格空气
}
```

- 从 `csy` 开始，**逐格向上**扫描
- 遇到第一个固体方块（天花板）就停止
- 扫描上限 64 格（防止无限循环导致卡死）
- 上限 **64** 格覆盖所有洞穴、下界空洞和露天场景

#### 2. 通道 → 找地板

```cpp
// PlayerHook.h:808-840
for (int fy = csy - 1; fy > -64; fy--) {
    Block block = getBlock(targetX, fy, targetZ);
    if (block is solid) {
        color = getBlockColor(block);  // 按方块类型取颜色
        break;
    }
}
```

- 从 `csy - 1` 开始**逐格向下**搜索
- 找到第一个非空气方块即为地板
- **无上限**，直到 Y=-64（世界底部）
- 如果完全没找到地板（深渊）→ 渲染深灰色

#### 3. 墙壁 → 黑色

只要空气检测后 `isAir == false`（整列都是固体），像素保持黑色。

### 颜色查找

- 使用生物群系数据获取草地/树叶/水的色调
- 600+ 种方块的颜色映射表（`getBlockColor()`）
- 缓存机制：`s_globalColorCache` 避免重复计算
- 群系缓存：`s_biomeCellX/Z` 减少群系查询次数

## 配置项

| 变量 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `caveMode` | `bool` | `false` | 是否洞穴模式（自动检测） |
| `caveScanY` | `int` | `0` | 当前扫描的 Y 基准高度 |
| `caveRange` | `int` | `3` | 旧逻辑保留，当前未使用 |

---

## 用户界面显示

DX11Hook.h 中，洞穴模式下在小地图下方显示：

```
洞穴 Y=64
```

大地图（Full Map）模式下，洞穴模式直接渲染 `g_mapTextureView` 全图纹理，而非地表模式的分块渲染。
